# 📱 Multi-Platform Contact Manager (Local CRUD)

A clean, modern, and user-friendly Contact Management application built using **Flutter**. This project is a comprehensive local database CRUD application engineered to deliver native performance from a single codebase across 6 major target platforms.

---

## 🚀 Target Platforms
*   **Mobile:** Android, iOS
*   **Desktop:** Windows, macOS, Linux
*   **Web:** Progressive Web App (PWA)

---

## 🛠️ Core Features & Capabilities
*   **Complete CRUD Lifecycle:**
    *   **Create:** Instantly add new contacts via a clean form interface.
    *   **Read:** View all saved contacts in a structured, fluid list layout.
    *   **Update:** Edit existing contact profiles and seamlessly persist changes.
    *   **Delete:** Remove records with simple interactive gestures or buttons.
*   **Local Storage Architecture:** Powered by a high-performance, platform-agnostic offline database ensuring total privacy and instantaneous load times.
*   **Dynamic Search:** Smart, real-time filtering to locate contacts by name dynamically as you type.
*   **⭐ Favorite Feature:** Integrated "Favorite Contact" toggle with an isolated view option to quickly display only your starred connections.

---

## 🗂️ Data Schema
Each managed contact profile comprehensively encapsulates:
1.  **ID:** Auto-generated unique identifier.
2.  **Name:** Contact full name string.
3.  **Phone Number:** Primary communication digit field.
4.  **Email Address:** Standard electronic mail address string.
5.  **Postal Address:** Physical address details layout.
6.  **Is Favorite:** Boolean flag indicating star/favorite status.

---

## 🎨 UI/UX Design Approach
While utilizing assignment parameters as layout guidelines, the user interface shifts away from exact pixel-perfect imitation. It incorporates modern custom iconography, cohesive custom color palettes, and optimized responsive padding to ensure an intuitive experience on both pocket-sized mobile screens and widescreen desktop displays.
